04 / METHOD

What this clock can—and cannot—tell you

The counter starts at the creation of #34227, selected because it explicitly describes the visible pet and its usable input area drifting apart. Earlier, display-specific reports are included as context. This is not a claim about the first occurrence of every pet bug.

GitHub state is administrative metadata. A closure, a duplicate suggestion, or a community workaround does not verify a shipped fix. This clock does not reset on closure, and this site does not claim to test each desktop release.

The initial selection follows a bounded chain of input and hit-region reports from May–August 2026. It omits many adjacent reports and references. Absence from this map is not absence of a report or of internal engineering work.

The site stores public issue metadata, short editorial summaries, and evidence links. Issue bodies, comments, attachments, and diagnostic identifiers stay on GitHub. No analytics, embedded credentials, or background API polling.
